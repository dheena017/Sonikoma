# Platform Shortcuts Module (`features/platform/shortcuts/`)

## 1. Executive Overview & Scope
The **Shortcuts Module** provides global and scoped keyboard shortcut management, key combination customization, and cheat sheet overlays.

## 2. Directory Inventory
- **`components/`**: `ShortcutList.tsx`, `ShortcutItem.tsx`, `ShortcutFilters.tsx`, `ShortcutsPageContent.tsx`.
- **`hooks/`**: `useShortcutsPage.ts`, `useShortcutRecording.ts`, `useShortcutPersistence.ts`.
- **`pages/`**: `ShortcutsPage.tsx`

# Platform Projects Components (`features/platform/projects/components/`)

## Overview
UI components responsible for project selection, workspace switching, and series status management across the platform.

## Catalog
- **`ActiveProjectSelectorDrawer.tsx`**: Slide-over drawer presenting user projects, recents, series filters, and quick switchers.
- **`ActiveProjectBar.tsx`**: Context bar displaying current active project title, cover thumbnail, and chapter progress.

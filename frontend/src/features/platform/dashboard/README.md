# Platform Dashboard Module (`features/platform/dashboard/`)

## 1. Executive Overview & Scope
The **Platform Dashboard** provides high-level workspace analytics, project recents, quick action entry points, and quick jump cards for comic creators.

## 2. Directory Inventory
- **`components/`**: Stats summary cards, recent activity carousels, quick start banners.
- **`hooks/`**: Dashboard metrics aggregators and activity streams.
- **`utils/`**: Time-ago formatters and project sorting heuristics.
- **`pages/`**: `DashboardPage.tsx`
